### L11: Don't Soften Adversarial Language [review]
**Date**: 2026-04-15
**Trigger**: User explicitly corrected softened review prompts. The CSFT project uses "FIND ERRORS", "try to BREAK", "WORTHLESS", "defeats the purpose". The initial BFSS critics were too polite.
**Rule**: Adversarial reviewers must be EXTREMELY AGGRESSIVE. Assume the work is wrong. Escalate severity when in doubt. Soft reviews are worse than no reviews because they create false confidence.
