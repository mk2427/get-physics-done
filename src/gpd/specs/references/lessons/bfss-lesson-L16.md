### L16: Every Project Needs an Equation Reference Document [conventions, equations]
**Date**: 2026-04-15
**Trigger**: 16 Fatals across 5 knowledge docs — convention drift, wrong signs, wrong normalizations, hallucinated formulas. The CSFT project solved this with knowledge/016 (42KB equation reference) that was the single source of truth for all equations.
**Rule**: Once Phase 1 knowledge docs reach Stable, MUST create an equation reference document that locks down all conventions, collects all key equations, and is the mandatory reference for all downstream computation. Without it, convention drift across sessions and agents is inevitable. This is non-negotiable for any project expected to last more than a few sessions.
