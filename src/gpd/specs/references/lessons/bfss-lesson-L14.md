### L14: One Equation Error Means the Entire Doc Is SUSPECT [knowledge, review]
**Date**: 2026-04-15
**Trigger**: Adversarial reviewer found FATAL algebra error in knowledge/001 virial theorem (K.9). Signs on F were flipped and factor of 3 missing. Also found K.6 self-inconsistency and K.7 index mismatch. All from a single doc built from MCP OCR.
**Rule**: If a knowledge doc review finds even ONE equation error, ALL equations in that doc must be re-verified — not just the one caught. One error proves the transcription process was unreliable. Also: knowledge docs require the most thorough review in the entire project because errors propagate silently into all downstream work.
