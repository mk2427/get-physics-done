### L13: Depth Over Breadth — One Focused Task Per Agent [agents, efficiency]
**Date**: 2026-04-15
**Trigger**: Re-review agents were each assigned to re-review an entire document (check all Round 1 issues + find new issues + propose improvements). They were too slow and shallow — trying to do too much in one context window.
**Rule**: An agent assigned multiple tasks will do shallow, lazy work on all of them. One focused task per agent. When a task has N independent parts, launch N agents. The marginal cost of launching an additional agent is tiny compared to the cost of a shallow review that misses a Fatal error. This is the #1 agent quality principle.
